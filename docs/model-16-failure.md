# Model 16 Failure Record

Model 16 was a failed model family and is closed as an architectural direction. Production never moved from Model 13.0.

- Model 16.0's 451,192-entry policy artifact covered 58.06% of contested held-out decisions, won only 43.4% against Model 13.0 and 41.3% against Model 15.2, and was rejected.
- Model 16.1's ordered-event reference build produced 242,303,750 records and a 6.30 GB matrix before a deployable asset existed.
- Model 16.2's full-observation exact lookup covered only 0.1%–0.2% of held-out positions and lost decisively.
- Model 16.3 removed exact lookup but did not establish a promotable successor.

The valid lesson retained from Model 16 is the legal-information boundary: an actor's decision cannot depend on hidden opponent information. Its observation-keyed policy artifacts, exhaustive transition assets, and Model 16 continuation plans are rejected. Historical implementation code and generated files may remain for provenance, but new model work must not build on Model 16 as a solution concept.
