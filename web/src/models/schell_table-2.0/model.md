# Schell Table 2.0

Rank-table discard model using Schell crib values.

- Discard logic: evaluates hand expectation over cuts and combines it with Schell crib tables.
- Crib logic: uses separate own-crib and opponent-crib Schell tables.
- Pegging logic: uses the base pegging behavior, without exhaustive pegging or peg-table discard EV.

Improvement over prior model: adds the Schell crib table family as an alternative rank-table foundation.
