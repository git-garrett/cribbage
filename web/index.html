    Tracking roadmap

    What the current data cannot answer

    Useful additions, ordered by their likely value to product decisions.

    1. Game milestone timingRecord hand starts, discard completion, pegging completion, hint use, decision time, and final margin to expose exactly where games slow down or stop.
    2. Reliable engaged timeAdd a low-frequency heartbeat while visible so duration survives missing page-exit events and can be split by screen.
    3. Request performanceRecord API route, response status, and duration buckets to connect slow or failed requests with user frustration.
    4. Durable anonymous return identityUse a long-lived random browser ID to measure repeat anonymous visits across tabs and days.
    5. Lightweight feedbackAdd an optional one-tap “How did that game feel?” response after completion and attach only the game stage and client context.
